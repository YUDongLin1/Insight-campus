## 产品定位

大学生日常信息高度分散：QQ 群、公众号、课程平台、学院通知、线下海报、班委转发、社团群和实习群不断刷屏。

**学生真正缺少的不是又一个提醒工具，而是能把碎片通知转成可执行行动的 AI 工作流。**

```
碎片信息输入 → AI 理解与结构化 → 日历执行 → 笔记沉淀 → QQ 频道分发 → 搭子匹配与路演复盘
```

## 解决的核心痛点

| 痛点 | 现状 | 校园情报官方案 |
|------|------|----------------|
| **信息太分散** | QQ 群、公众号、海报、截图散落各处 | 统一入口粘贴/上传，AI 自动解析 |
| **通知不能执行** | 文本通知需要手动提取时间、拆任务 | 自动提取主题/时间/地点/行动项 |
| **海报截图难处理** | 传统 OCR 只识别文字，不理解语义 | 多模态 AI 同时识别文字和视觉信息 |
| **资料难沉淀** | 灵感、洞察、行动清单丢在聊天记录 | 随身笔记 + QQ 频道卡片沉淀 |

## 核心功能

### 🧠 情报中心
粘贴 QQ 群通知、课程 DDL、活动公告、比赛信息，AI 自动提取主题、时间、地点、类型、优先级和下一步行动。

### 🖼️ 海报/截图识别
上传校园海报或截图，多模态 AI 同时完成 OCR 文字识别和图片语义理解，提取标题、时间、地点、报名方式等关键信息。

### 💡 智能洞察
根据通知类型生成差异化准备建议和 PCG 场景联动建议（QQ 频道分发、腾讯文档沉淀、腾讯新闻补充背景等）。

### 📅 情报日历
将任务同步到日历，支持倒计时提醒、按日期查看、手动添加/删除日程、中文时间解析（"4月30日 23:59"、"周三 19:00"）。

### 📝 随身笔记
沉淀产品洞察、路演材料、访谈结论和个人备忘，支持标签管理和自定义分类。

### 📡 搭子雷达
基于共同日程和兴趣标签，展示学习、比赛、求职或社团搭子匹配。

### 🤖 模拟面试 Agent
围绕产品定位、用户痛点、AI 能力、PCG 生态和商业化进行追问，帮助准备路演和产品面试。

## 快速体验

### 方式一：静态演示版（推荐）

无需后端、无需 API Key，双击即可体验全部功能：

```bash
# 直接用浏览器打开
static-demo.html
```

或部署到 GitHub Pages / Netlify / Vercel 后分享链接。

> 静态版使用 CDN 加载 React、Babel 和 Tailwind，需要联网。

### 方式二：完整后端版

接入真实大模型 API，体验完整 AI 能力：

```bash
# 1. 克隆仓库
git clone https://github.com/YOUR_USERNAME/insight-campus.git
cd insight-campus

# 2. 安装依赖（零依赖，仅需 Node.js）
# 3. 配置环境变量
cp .env.example .env
# 编辑 .env 填入 API Key

# 4. 启动服务
node server.js

# 5. 打开浏览器
# http://localhost:3001
```

**环境要求**：Node.js 18+

### AI 提供商配置

支持多种大模型 API，可在前端 AI 控制台或 `.env` 中配置：

| 提供商 | 模型 | 配置方式 |
|--------|------|----------|
| **智谱 BigModel** | GLM-4.7 / GLM-4.5V | `BIGMODEL_API_KEY` |
| **腾讯混元** | hunyuan-turbos-latest | `TENCENT_SECRET_ID` + `TENCENT_SECRET_KEY` |
| **OpenAI** | GPT-3.5/4 | `OPENAI_API_KEY` |
| **Anthropic** | Claude 3 | `ANTHROPIC_API_KEY` |
| **DeepSeek 等** | 自定义 OpenAI 兼容 API | 前端控制台配置 |

未配置密钥时自动使用本地规则解析（Mock 模式），适合演示。

### 技术栈

- **前端**：React 18 + Tailwind CSS 3（CDN 加载，零构建）
- **后端**：Node.js 18+ 原生 HTTP（零依赖）
- **AI 接入**：智谱 BigModel / 腾讯混元 / OpenAI / Anthropic / 自定义兼容 API
- **多模态**：智谱 GLM-4.5V 视觉模型 + OCR.space 兜底
- **数据存储**：浏览器 localStorage（静态版）

## AI 能力

本产品的 AI 不是装饰功能，而是核心生产力。去掉 AI，产品会退化为普通日历和笔记工具。

| AI 能力 | 应用场景 |
|---------|----------|
| 大模型文本理解 | 解析群聊通知、DDL、公告 |
| 多模态图片理解 | 识别海报/截图中的文字和视觉信息 |
| 信息结构化生成 | 输出任务、时间、地点、行动项和分享卡片 |
| 智能建议生成 | 根据比赛/讲座/招聘/DDL 类型给出差异化准备建议 |
| Agent 式问答 | 模拟评委/面试官追问，训练路演和面试表达 |

## 产品设计思路

### 用户洞察
- **目标用户**：18-25 岁中国高校学生（本科生、研究生、社团成员、学生干部、求职学生）
- **核心场景**：收到 QQ 群通知后快速转成行动计划；看到校园海报后直接上传识别
- **关键路径**：信息输入 → AI 解析 → 任务提取 → 日历同步 → 笔记沉淀 → QQ 频道分发

### 与同类产品的差异化

| 对比维度 | 日历工具 | OCR 工具 | 通用大模型 | **校园情报官** |
|----------|----------|----------|------------|----------------|
| 信息输入 | 手动输入 | 图片识别 | 文本对话 | 群聊+海报+截图 |
| 理解能力 | 无 | 文字识别 | 通用理解 | 校园语义理解 |
| 输出形态 | 日程 | 文字 | 对话文本 | 任务+洞察+卡片 |
| 执行闭环 | 仅提醒 | 仅识别 | 仅回答 | 日历+笔记+分发 |

### 验证指标设计

- **效率指标**：单条通知整理时间从 2-5 分钟 → 10-20 秒
- **准确性指标**：时间地点提取准确率、活动类型识别准确率
- **行为指标**：日历同步率、分享卡片生成率、笔记保存率
- **结果指标**：漏看 DDL 次数下降、比赛提交完成率提升

## 商业化思考

1. **Freemium 个人会员**：免费基础功能 + 付费高级能力（更高识别额度、历史检索、智能周报）
2. **校园组织版 SaaS**：面向社团/学院/就业中心提供组织后台
3. **PCG 生态增值**：与 QQ 频道、腾讯文档、腾讯新闻/视频联动
4. **校园招聘赛事服务**：为企业宣讲和赛事活动提供结构化触达

## 安全提醒

- `ai-config.json` 和 `.env` 可能包含 API Key，公开提交前请删除真实密钥
- 建议将 Key 放在服务器环境变量中，不要提交到代码仓库
